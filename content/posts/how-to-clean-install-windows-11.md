<div class="key"><b>In short:</b> A clean install of Windows 11 wipes your drive and starts fresh. Boot from an 8 GB or larger USB stick made with Microsoft&#x27;s Media Creation Tool (or Rufus). Back up your files first, delete the old Windows partition during setup, then run Windows Update and check activation after first boot.<ul><li>Media Creation Tool is the safe default; Rufus is the tool when your PC fails Windows 11&#x27;s hardware checks.</li><li>At the install screen, delete only the large &#x27;Primary&#x27; partition on your main drive, not small recovery or EFI partitions.</li><li>You can still set up without a Microsoft account on recent releases: disconnect from Wi-Fi and use the local-account path.</li><li>If BitLocker is on, decrypt the drive or save the recovery key before wiping, or a repartitioned encrypted drive becomes unrecoverable.</li><li>Browser passwords only sync back if you enabled sync before the wipe: otherwise they&#x27;re gone.</li></ul></div>
<h2>Clean install vs upgrade vs Reset this PC</h2>
<p>There are three ways to get a fresh Windows 11 on a computer, and they are not interchangeable. An upgrade keeps your files and programs and swaps the system underneath. That&#x27;s the gentle option but it carries old problems with it. &#x27;Reset this PC&#x27; reinstalls Windows from a copy stored on the machine. It can keep or remove your files, but it reuses the same system files. If those files are corrupted, the reset can fail half way.</p>
<p>A clean install wipes the Windows drive. It lays down a completely new copy from the USB. That&#x27;s why it&#x27;s the one that actually fixes a slow, glitch-ridden computer. Choose it when the PC has slowed badly, when malware keeps coming back, or when an upgrade went wrong. It also works when you&#x27;re selling the machine or starting fresh with a second-hand one.</p>
<p>Plan anywhere from 30 minutes to a few hours; if you have many updates or slow drives, allow more time. You start from a known-good state.</p>

<h2>Back up what matters first: what to copy and where</h2>
<figure class="fig"><img src="https://tse2.mm.bing.net/th?q=external+hard+drive+copying+files+beside+a+laptop&amp;w=560&amp;h=380&amp;c=7&amp;rs=1&amp;p=0&amp;o=5&amp;pid=1.7" alt="external hard drive copying files beside a laptop" loading="lazy" decoding="async"></figure>
<p>A clean install erases the drive it installs to, and there&#x27;s no undo. Copy your files somewhere the installer cannot reach. Use an external USB hard drive, a large USB stick, or a cloud service such as OneDrive, Google Drive or Dropbox. Many home users can back up personal files to a 500 GB to 1 TB drive. Check your current used space in Settings &gt; System &gt; Storage to be sure. The backup drive and the installer stick must be two different USB devices.</p>
<p>Work through the usual hiding places, not just the obvious folders. Windows keeps your personal files under C:\Users\YourName. That covers Documents, Desktop, Pictures, Videos, Downloads and Music. Beyond that, check the AppData folder for browser bookmarks if you don&#x27;t sync them. Check for the Outlook data file if you use desktop email, and any folder your phone backs up to over Wi-Fi. Game saves often live in Documents or in AppData too.</p>
<p>Write down the names of the programs you actually use and where their licence keys are. A clean install means reinstalling them. A quick browser-bookmark trick: sign in to your Google or Microsoft account in the browser and turn on sync. Your bookmarks come back automatically after the install. Two minutes now saves an evening of reconstruction later. But passwords only sync back if you enabled sync before the wipe. If you didn&#x27;t, and you&#x27;ve forgotten them, they&#x27;re gone.</p>
<ul><li>C:\Users\YourName - Documents, Desktop, Pictures, Videos, Downloads, Music</li><li>AppData\Roaming: app settings, email data files, some game saves</li><li>Browser bookmarks: turn on sync or export an HTML file</li><li>Program list and licence keys: note them before you wipe</li></ul>
<div class="note"><b>Check this:</b> Check the backup before you wipe. Open a few copied files on the other drive to make sure they actually copied.</div>
<h2>Check for BitLocker before you wipe</h2>
<p>If your PC has BitLocker drive encryption turned on, the installer will stall when it tries to wipe the encrypted drive. Open Settings &gt; Privacy &amp; security &gt; Device encryption (or System &gt; About &gt; BitLocker settings on Pro). If it says BitLocker is on, you have two choices. Suspend keeps the drive readable across a few reboots. The safest route is to decrypt the drive (turn BitLocker off) before a clean install. Or save the recovery key first: a wiped and repartitioned encrypted drive is unrecoverable without it.</p>
<p>Laptops that shipped with Windows 11 often have device encryption on by default. Check even if you don&#x27;t remember turning it on.</p>
<h2>Making the bootable USB: Media Creation Tool or Rufus</h2>
<p>You need a USB stick of at least 8 GB. Anything on it will be erased, so use a blank one or one you can wipe. The official route is Microsoft&#x27;s Media Creation Tool. Download it from Microsoft&#x27;s Windows 11 download page on any working PC, run it, and choose &#x27;Create installation media&#x27;. Pick USB. The tool downloads the installer and writes the USB. On a typical broadband connection this can take tens of minutes, longer on slow connections or with older USB sticks. This is the route to use if your PC meets Windows 11&#x27;s requirements and you just want a reliable installer.</p>
<p>The alternative is downloading the Windows 11 ISO file and writing it to the stick with Rufus, a small free utility. Rufus matters when Microsoft&#x27;s checks would block you. A standard Windows 11 install requires TPM 2.0, Secure Boot and certain CPUs. If your PC fails those checks, Rufus&#x27;s extended installation options let it build a stick that skips the TPM and Secure Boot requirements. It also removes the Microsoft account requirement during setup. On a second-hand laptop full of manufacturer software, a Rufus stick built from a clean ISO sidesteps the bundled extras that OEM images restore.</p>
<p>For everyone else, Media Creation Tool is the safer default. Fewer choices to get wrong.</p>

<h2>Booting from the USB and picking the right partition</h2>
<p>With the stick made and the backup verified, check your drive size first. Open Settings &gt; System &gt; Storage before you boot the USB. Then you&#x27;ll know which partition number or size to delete later. Then plug the USB stick into the PC you&#x27;re reinstalling and restart. As the machine starts, press the boot-menu key repeatedly. The common ones are F12, F2, Esc and Del, and it varies by maker. Search your laptop model plus &#x27;boot menu key&#x27; if none works. Choose the USB entry from the menu. Pick the one labelled UEFI if two appear. The Windows installer will load after a minute or two.</p>
<p>If the USB never shows in the boot menu, re-create the stick with Media Creation Tool. Try a different USB port: a rear port on a desktop, or a USB-A port rather than a hub. Make sure Fast Boot is off in the BIOS settings.</p>
<p>Click through the language and &#x27;Install now&#x27; screens. At the &#x27;Where do you want to install Windows?&#x27; screen you&#x27;ll see a list of partitions: slices of your drive. The safe pattern is to select the largest &#x27;Primary&#x27; partition on your main drive, click Delete, then select the resulting &#x27;Unallocated Space&#x27; and click Next.</p>
<p>You can leave the small system partitions alone (EFI, recovery, MSR). They&#x27;re system plumbing. Or delete them all if you want a guaranteed clean partition table. The installer recreates what it needs. The one thing not to delete is any partition several hundred gigabytes in size on a second drive or an external disk.</p>
<p>If your system has more than one internal drive, check the disk number or size to confirm which is which. Disk 0 is usually the main system drive, but not always. When in doubt, unplug every other drive before you start the install. That makes the list unambiguous. Windows will restart several times. Leave the USB in until you reach the desktop.</p>
<ol class="steps"><li>Restart the PC and tap the boot-menu key (F12, F2, Esc or Del).</li><li>Select the UEFI entry for your USB stick.</li><li>Choose language and &#x27;Install now&#x27;, entering your product key or clicking &#x27;I don&#x27;t have a product key&#x27;.</li><li>Choose Custom: Install Windows only.</li><li>Delete the large Primary partition on your main drive, select the Unallocated Space, and click Next.</li></ol>
<div class="note warn"><b>Warning:</b> Unplug every other drive and USB storage device before installing. The only large partition on the list should then be the one you mean to erase.</div>
<h2>What to do about the OEM recovery partition on a laptop</h2>
<figure class="fig"><img src="https://tse1.mm.bing.net/th?q=how+to+clean+install+windows+11+OEM+recovery+partition+laptop&amp;w=560&amp;h=380&amp;c=7&amp;rs=1&amp;p=0&amp;o=5&amp;pid=1.7" alt="how to clean install windows 11 - What to do about the OEM recovery partition on a laptop" loading="lazy" decoding="async"></figure>
<p>Many laptops ship with a factory recovery partition: a chunk of the drive that holds the manufacturer&#x27;s original Windows image and bundled software. It&#x27;s often several gigabytes and shows up in the partition list during install. You can leave it alone if you want the option to restore the laptop to factory settings later using the manufacturer&#x27;s recovery tools. Delete it if you want a completely clean slate and don&#x27;t care about the factory image. The recovery partition takes up space but doesn&#x27;t interfere with a clean Windows 11 install.</p>
<h2>Home vs Pro, and skipping the Microsoft account</h2>
<p>For a clean install, the edition question mostly answers itself. Windows 11 Home is what almost every consumer PC ships with. If the machine was ever activated, the licence is stored on Microsoft&#x27;s servers against your hardware. Leave the product key box empty (&#x27;I don&#x27;t have a product key&#x27;). Choose the edition the PC previously ran. Windows will reactivate automatically once it reaches the internet. If the PC was never activated (a self-built machine, for example), you do need a valid product key for the edition you choose.</p>
<p>Pro adds extras such as BitLocker drive-encryption management and joining a work domain. Useful for small businesses, unnecessary for a home laptop. You can&#x27;t cleanly switch editions in the same install, so pick the one the machine already had.</p>
<p>During setup, recent versions push hard toward a Microsoft account. If you want a local account instead, disconnect from the internet at the network screen: skip Wi-Fi, or unplug the Ethernet cable. When setup asks for a network and can&#x27;t find one, choose &#x27;I don&#x27;t have internet&#x27;, then &#x27;Continue with limited setup&#x27;. You can create a local account with just a username and password. This offline path has worked on recent releases. Microsoft keeps tightening it, though. If the option disappears, a Rufus stick built with the local-account option is the reliable fallback.</p>
<p>Whichever route you take, the local account is fully usable. You can switch to a Microsoft account later if you change your mind, so there&#x27;s no penalty for starting offline.</p>
<h2>First boot: the checklist that makes the install stick</h2>
<figure class="fig"><img src="https://tse3.mm.bing.net/th?q=Windows+Update+progress+on+a+freshly+installed+laptop&amp;w=560&amp;h=380&amp;c=7&amp;rs=1&amp;p=0&amp;o=5&amp;pid=1.7" alt="Windows Update progress on a freshly installed laptop" loading="lazy" decoding="async"></figure>
<p>Reaching the desktop isn&#x27;t the finish line. An hour of housekeeping makes the difference between a fresh install and a half-finished one. First, update everything. Open Settings &gt; Windows Update &gt; Check for updates, install everything offered, and restart as many times as it asks. This pulls in drivers for graphics, Wi-Fi and the chipset. That&#x27;s why the Wi-Fi or screen may look odd until it finishes. If something still lacks a driver (often the touchpad or card reader on laptops), get it from the manufacturer&#x27;s support page for your exact model. Avoid random &#x27;driver updater&#x27; sites.</p>
<p>Second, confirm activation. Settings &gt; System &gt; Activation should say Windows is activated with a digital licence. If it doesn&#x27;t, run the troubleshoter on that same page. The licence was tied to the hardware before the wipe, so it almost always clears itself.</p>
<p>Third, restore your files from the backup. Sign in to the browser to resync bookmarks, and reinstall your programs from your list one at a time. If you used a Rufus stick with the TPM or Secure Boot workaround, check the BIOS settings after install. Windows 11 24H2 and later can run with those features re-enabled. Turning them back on improves security. Create a restore point. Go to Settings &gt; System &gt; About &gt; System protection. That path is current as of recent builds; search Start for &#x27;Create a restore point&#x27; if it has moved. Then set up a real backup habit. A monthly copy to that external drive means the next reinstall is a non-event rather than a rescue mission.</p>
<p>If your laptop came with manufacturer utilities, reinstall the maker&#x27;s app. Lenovo Vantage, MyASUS and HP Command Center restore hotkey functions and firmware-update features.</p>
<p>One note for the newest ARM-based laptops with Snapdragon chips: use the manufacturer&#x27;s own recovery or Microsoft&#x27;s ARM-aware media. The standard x86 USB method described here isn&#x27;t made for them.</p>
<div class="note"><b>Tip:</b> Do Windows Update first, before reinstalling programs. Many &#x27;missing driver&#x27; panics resolve themselves after the first round of updates.</div>
<div class="note"><b>Our take:</b> A clean install is the most reliable way to revive a struggling Windows 11 PC, provided the backup happens first.</div>
<h2>Quick answers</h2>
<h3>Will a clean install remove my personal files?</h3>
<p>Yes: everything on the drive you install to is erased, including Documents, Desktop and Pictures. That&#x27;s why backing up to a separate drive or the cloud is step one, not an afterthought.</p>
<h3>Do I need to buy a new Windows 11 licence for a clean install?</h3>
<p>Usually not. If the PC was activated before, the digital licence is recorded against the hardware and Windows reactivates automatically once online. Check Settings &gt; System &gt; Activation after first boot.</p>
<h3>Can I skip the Microsoft account during setup?</h3>
<p>Yes, on recent releases. Disconnect from the internet at the network screen and choose the local-account option when setup asks for a network.</p>
<h3>My PC doesn&#x27;t meet the TPM 2.0 requirement. Can I still install Windows 11?</h3>
<p>Yes, by building the USB with Rufus and enabling its option to remove the TPM, Secure Boot and account requirements. Microsoft doesn&#x27;t support this path, but it works widely on older hardware.</p>
<h3>Is &#x27;Reset this PC&#x27; good enough instead of a clean install?</h3>
<p>Try it first if you only want a tidy-up and your files are backed up. But a reset reuses the system files already on the drive. It can fail on a corrupted system. A clean install from USB is the more reliable fix.</p>
<h3>How long does a clean install take?</h3>
<p>Plan anywhere from 30 minutes to a few hours. The time depends on USB speed, drive speed, and how many updates Windows needs. Plan for half a day overall if you have a lot of software to restore.</p>
