<h2>How to screenshot on Windows 11: the fastest route</h2>
<p>You can screenshot on Windows 11 with tools already built into the system. Microsoft&#x27;s Windows help pages describe <strong>Snipping Tool</strong> as the main way to capture part of the screen. Snipping Tool means the built-in app that grabs a chosen area. No download is needed.</p>
<p>Press <strong>Windows logo key + Shift + S</strong> and the screen dims slightly while a small capture toolbar appears at the top. Pick a capture mode from that toolbar. Drag, click or draw to finish the shot.</p>
<p>The capture copies to the <strong>clipboard</strong> straight away. Clipboard means the temporary holding area for copied items. Press Ctrl + V to paste the image into mail, chat or a document. A notification also appears so you can open and edit the shot.</p>
<p>Microsoft says snips are also saved in <strong>Pictures &gt; Screenshots</strong> when auto-save is on. Check that folder if you need a file later. Paste first if the shot matters. Clipboard contents change when you copy something new.</p>
<p>Menus that close when you click elsewhere need a delay before capture. Open the Snipping Tool app from Start instead of the shortcut. Set a delay in the app, open the menu you want, then let the capture start. The menu stays open for the shot. Hover states work the same way.</p>
<ol class="steps"><li>Get the window, page or error message ready on screen.</li><li>Press Windows logo key + Shift + S.</li><li>Pick Rectangle, Window, Full screen or Freeform on the toolbar at the top.</li><li>Drag over the area, click the window, or draw the shape to capture it.</li><li>Press Ctrl + V to paste the shot, or click the notification to edit and save it.</li></ol>
<div class="note"><b>Tip:</b> Need to paste into chat right now? Windows + Shift + S is the shortcut to use.</div>

<h2>Snipping Tool modes pick the right shape for the job</h2>
<figure class="fig"><img src="https://tse4.mm.bing.net/th?q=windows+snipping+tool+toolbar+on+screen&amp;w=560&amp;h=380&amp;c=7&amp;rs=1&amp;p=0&amp;o=5&amp;pid=1.7" alt="windows snipping tool toolbar on screen" loading="lazy" decoding="async"></figure>
<p>Snipping Tool gives you four capture modes for a still image, and Microsoft lists them as <strong>Rectangle</strong>, <strong>Freeform</strong>, <strong>Window</strong> and <strong>Full screen</strong>. Each mode answers a different need. Picking the right mode saves cropping later.</p>
<p>Rectangle lets you drag a box around exactly what you want. Use it for part of a web page, a chart or an error message. Freeform lets you draw any shape with the mouse. Use Freeform when the area has an odd outline.</p>
<p>Window captures one open window cleanly when you click it. That suits an app, a dialog box or a browser window. Full screen captures everything on the display at once. That suits tutorials or proof of a full error state.</p>
<p>Microsoft says the Windows 11 Snipping Tool combines the old Snipping Tool with Snip &amp; Sketch. One app now covers both older tools. The editor after capture lets you crop, draw and highlight. Save the result as PNG or JPG, or copy it with Ctrl + C.</p>
<p>Text tools sit in the same editor on current versions. Microsoft describes <strong>Text Actions</strong> for copying text found inside a screenshot. Quick Redact can black out sensitive details it detects. Check the result before you share it. Tools can miss details.</p>
<ul><li>Rectangle: drag a box for part of a page or one error message.</li><li>Window: click one app window for a clean shot with no desktop around it.</li><li>Full screen: grab every display at once when context matters more than size.</li><li>Freeform: draw an irregular shape when a box would include too much.</li></ul>

<h2>Print Screen shortcuts save files or copy one window</h2>
<p>The Print Screen key sits near the top right of most keyboards. Microsoft notes it may say <strong>Print Screen</strong>, <strong>PrtSc</strong>, <strong>PrtScn</strong> or <strong>PrntScrn</strong>. Laptop keyboards often share the key with another function. You may need the Fn key as well.</p>
<p>Press <strong>Windows logo key + Print Screen</strong> to save the whole screen as a file, and Microsoft Support says the image lands in the Screenshots subfolder of Pictures. The file format is PNG. Open File Explorer, then go to Pictures &gt; Screenshots to find it.</p>
<p>Press <strong>Alt + Print Screen</strong> to copy only the active window. Active window means the window you are working in now. Click that window first, then press the keys. Paste with Ctrl + V where you need the image.</p>
<p>Alt + Print Screen saves no file. That is the catch. Copy text or another image and the screenshot is gone. Paste it straight away, or save it from an app after pasting. Use Windows + Print Screen when losing the shot would hurt.</p>
<p>Print Screen on its own now opens screen snipping by default. Microsoft Support lists that as the current Windows behaviour. You select a region to capture to the clipboard. Snipping Tool can then share or mark up the image.</p>
<ol class="steps"><li>For a saved full-screen file, press Windows logo key + Print Screen.</li><li>Open File Explorer from the taskbar.</li><li>Go to Pictures, then Screenshots, and open the newest PNG file.</li><li>For one window only, click the window, press Alt + Print Screen, then paste with Ctrl + V.</li></ol>
<div class="note"><b>Check this:</b> Click the window you want first. Alt + Print Screen captures the window in focus.</div>
<h2>Change the Print Screen key back if you prefer the old way</h2>
<p>Some people prefer the older Print Screen behaviour. Older behaviour means the key silently copies the whole screen. No toolbar appears. You paste the image where you need it. Microsoft Support gives the exact setting to change this.</p>
<p>Open <strong>Settings &gt; Accessibility &gt; Keyboard</strong> on Windows 11 and find <strong>Use the Print Screen button to open screen snipping</strong> in the keyboard options. Set that option to Off. Print Screen then copies the full screen again. Windows + Shift + S still opens Snipping Tool.</p>
<p>Leave the setting On if you often capture part of the screen. The toolbar gives you Rectangle, Window, Full screen and Freeform each time. That saves a crop step later. Turn it Off only when full-screen copies are your normal habit.</p>
<p>A common belief says Print Screen is broken when the toolbar appears. That belief is wrong. Microsoft changed the default on purpose. The key still works. It now asks what area you want first. Your choice in Settings decides which way it behaves.</p>
<p>Check the setting again after a big Windows update. Defaults can change between versions. The path stays in Accessibility &gt; Keyboard on current Windows 11 builds. Search Settings for Print Screen if labels move. Confirm the toggle before you rely on the key.</p>
<ol class="steps"><li>Select Start, then Settings.</li><li>Go to Accessibility &gt; Keyboard.</li><li>Find the Print Screen snipping toggle in that list.</li><li>Set it to Off for the old copy-full-screen behaviour, or On to keep the snipping toolbar.</li></ol>
<h2>Game Bar and tablets cover shots other tools miss</h2>
<p>Full-screen games can hide the snipping toolbar. Microsoft&#x27;s Xbox Game Bar has its own capture shortcut for that case. Game Bar means the overlay built into Windows for games and apps. Press <strong>Windows logo key + G</strong> to open it.</p>
<p>Press <strong>Windows logo key + Alt + Print Screen</strong> to take a screenshot in a game or app, and Microsoft Support says the image saves as a PNG in the Captures folder. Find it under Videos &gt; Captures. Clips from Game Bar land in the same folder.</p>
<p>Game Bar captures the game or app in focus. Focus means the window receiving your keyboard input. It does not let you drag a region. Use Snipping Tool for region shots on the desktop. Use Game Bar when the game covers the screen.</p>
<p>Windows tablets use buttons instead of keys. On many Surface devices, press and hold Power and press Volume Up. Press both at the same time. Release them after the capture. Other tablet makers use their own button combination, so check the device manual if that pair does nothing.</p>
<p>Surface and laptop keyboards vary by model. Some need Fn with Print Screen. Microsoft Support also lists <strong>Fn + Windows logo key + Space Bar</strong> for devices without a PrtScn button. Try Windows + Shift + S first. That shortcut needs no Print Screen key at all.</p>
<ul><li>Game screenshot: Windows + Alt + Print Screen, saved to Videos &gt; Captures.</li><li>Game overlay: Windows + G opens Game Bar over the game or app.</li><li>Tablet shot: on many Surface devices, Power + Volume Up together.</li><li>No Print Screen key: Windows + Shift + S opens snipping without it.</li></ul>
<h2>Record the screen and find every file afterwards</h2>
<p>A still image sometimes fails to show a problem. Snipping Tool can record video of an area you select. Microsoft lists <strong>Windows logo key + Shift + R</strong> for video capture. The screen dims and the capture toolbar appears, as with a still snip.</p>
<p>Open Snipping Tool and switch from <strong>Snip</strong> to <strong>Record</strong>, then select the portion of the screen you want to record before you start. Select Start, then Stop when you finish. Microsoft says the video saves to the Screen Recordings folder automatically. You can toggle the microphone for voiceover.</p>
<p>Screen recordings land in <strong>Videos &gt; Screen Recordings</strong> as MP4 files. Game Bar captures land in Videos &gt; Captures. Clipboard-only shots land nowhere until you paste and save them. Folder choice tells you which tool made the file. Auto-save for snips can be changed in Snipping Tool settings.</p>
<p>Recording and the editor text tools depend on your Windows 11 version. Microsoft describes them as Windows 11 Snipping Tool features. Older builds may lack Record, Text Actions or Quick Redact. Update Windows and Snipping Tool if a button is missing. The basic shortcuts still work on older builds.</p>
<p>Keep the shot you need and delete the rest. Screenshots pile up fast in Pictures &gt; Screenshots. Old error shots and receipts linger for years. Clear the folder now and then. Keep only files you may need as proof later.</p>
<ol class="steps"><li>Press Windows logo key + Shift + R, or open Snipping Tool and switch to Record.</li><li>Select the area of the screen you want to record.</li><li>Select Start and do the action you need to show.</li><li>Select Stop, then find the MP4 file in Videos &gt; Screen Recordings.</li></ol>

<h2>Quick answers</h2>
<h3>Why did Print Screen stop copying the whole screen?</h3>
<p>Windows 11 now opens screen snipping when you press Print Screen by default. You pick an area, then paste or edit the shot. Turn that behaviour off under Settings &gt; Accessibility &gt; Keyboard if you want the older copy-only action back.</p>
<h3>Where did my screenshot go?</h3>
<p>Look in File Explorer under Pictures for shots saved as files. A clipboard-only shot has no file to find. Paste that shot into an app and save it there if you need to keep it.</p>
<h3>Can Snipping Tool capture a long scrolling page?</h3>
<p>Snipping Tool has no scrolling capture mode. Take two or three overlapping snips and stitch them, or use a dedicated scrolling-capture tool. Overlap each shot a little so no line goes missing.</p>
<h3>What if my keyboard has no Print Screen key?</h3>
<p>Use Windows logo key + Shift + S instead. That shortcut opens the same snipping toolbar without Print Screen. Some devices without the key also use Fn + Windows logo key + Space Bar, per Microsoft Support.</p>
